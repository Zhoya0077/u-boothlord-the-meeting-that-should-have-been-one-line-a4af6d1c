One sentence that could have replaced an entire pointless meeting — no context, no explanation, just the line that kills the meeting.

## The entry

> The update is: nothing changed, nobody's blocked, and the only thing we decided was to have another meeting about this meeting.

## How it works

`main.ts` writes that single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Before writing, a self-checking gate validates the entry: 1–200 characters, not only whitespace, a single line, and a single sentence — throwing on failure so an invalid entry never reaches the judge.

## Run

```sh
node main.ts
```
